# Architektur in München

Interaktive Stadtpläne zur Münchner Architektur in neun Epochen, vom Mittelalter bis heute.

- **Handy-App** (Standort, Nähe-Liste, Rundgänge): https://bstriegl.github.io/architektur-muenchen/ · Anleitung: `anleitung.html` / `anleitung.pdf`
- **Pläne für PC und Beamer**: https://bstriegl.github.io/architektur-muenchen/plaene/ · Anleitung: `plaene/anleitung.html` / `plaene/anleitung.pdf` · alles offline: `plaene/Architektur_Muenchen_offline.zip`
